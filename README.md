# 🌉 TalkBridge — مكالمات فيديو بترجمة فورية

TalkBridge هو تطبيق مكالمات فيديو متكامل مع **ترجمة صوتية فورية** بين اللغات. تكلم بلغتك والطرف الآخر يسمعك بلغته!

![TalkBridge](https://img.shields.io/badge/TalkBridge-Video_+_Translation-6366f1?style=for-the-badge)

## ✨ المميزات

### 📹 مكالمات الفيديو
- **فيديو عالي الجودة** — كاميرا HD مع صوت واضح
- **مشاركة الشاشة** — شارك شاشتك أو نافذة معينة
- **دردشة نصية** — رسائل فورية مع ترجمة تلقائية
- **رابط دعوة** — شارك الرابط مباشرة للانضمام

### 🎤 الترجمة الصوتية الفورية
- **صوت طبيعي** — استخدم ElevenLabs للحصول على صوت بشري حقيقي
- **13+ لغة** — العربية، الإنجليزية، الفرنسية، الألمانية، الصينية، اليابانية...
- **نسخ مكتوب** — شاهد النص الأصلي والمترجم في نفس الوقت
- **ترجمة الدردشة** — ترجمة تلقائية للرسائل النصية

### 🔊 جودة الصوت
| المزود | الجودة | التكلفة |
|--------|--------|---------|
| **ElevenLabs** ⭐ | صوت طبيعي مثل الإنسان | مجاني (محدود) |
| Browser | جودة متوسطة | مجاني |
| Coqui XTTS | صوت عالي الجودة | خادم محلي |

## 🚀 التشغيل

### المتطلبات
- **Node.js** 18+
- **مفتاح Groq API** — [احصل عليه مجاناً](https://console.groq.com)
- **مفتاح ElevenLabs** (موصى به) — [احصل عليه](https://elevenlabs.io)

### التثبيت

```bash
npm install
npm run dev
```

### الإعداد

1. افتح التطبيق في المتصفح
2. اضغط على ⚙️ **الإعدادات**
3. أدخل **مفتاح Groq API** (مطلوب)
4. اختر **ElevenLabs** كمزود الصوت وأدخل المفتاح (موصى به للصوت الطبيعي)
5. اضغط **تم**

## 🎯 كيفية الاستخدام

### بدء اجتماع (المضيف)
1. اضغط **"بدء اجتماع"**
2. اختر لغتك (مثلاً: العربية)
3. اختر لغة الطرف الآخر (مثلاً: الإنجليزية)
4. **انسخ رابط الدعوة** وأرسله للشخص الآخر
5. اضغط **"بدء الاجتماع"**

### الانضمام للاجتماع (الضيف)
1. افتح **رابط الدعوة** الذي استلمته
2. أدخل اسمك واختر لغتك
3. اضغط **"انضم الآن"**

## 🛠 التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| **الواجهة** | React 19, TypeScript, Vite, Tailwind CSS |
| **الاتصال** | PeerJS (WebRTC) |
| **الحالة** | Zustand |
| **التعرف على الكلام** | Groq Whisper |
| **الترجمة** | Groq LLaMA 3.3 70B |
| **تحويل النص لصوت** | ElevenLabs / Browser / Coqui |

## 🔊 إعداد ElevenLabs (للصوت الطبيعي)

للحصول على أفضل جودة صوت:

1. سجل في [elevenlabs.io](https://elevenlabs.io)
2. احصل على API Key من الإعدادات
3. في TalkBridge: الإعدادات → اختر ElevenLabs → الصق المفتاح

## 📋 متغيرات البيئة

| المتغير | مطلوب | الوصف |
|---------|-------|-------|
| `GROQ_API_KEY` | ✅ | للتعرف على الكلام والترجمة |
| `ELEVENLABS_API_KEY` | موصى به | للصوت الطبيعي |
